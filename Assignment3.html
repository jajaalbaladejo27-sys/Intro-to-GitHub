What is Git?

Local Distributed VCS

Git is a free, open-source distributed version control system installed on your local machine. Created by Linus Torvalds in 2005, it tracks changes in your source files over time, keeping a complete history locally without requiring internet connectivity.

Key Properties:

  • Command-line utility operating on disk
  • Creates DAG (Directed Acyclic Graph) history
  • Completely offline capabilities

What is GitHub?

Cloud Platform & Social Coding

GitHub is a cloud platform that hosts Git repositories online. It provides a visual graphical user interface (GUI), web-based file browsing, issue tracking, continuous integration (CI/CD via Actions), pull requests, and multi-developer collaboration toolsets.

Key Properties:

  • Online centralized remote host
  • Pull Requests, Discussions & Code Reviews
  • Built-in web hosting via GitHub Pages

TASK 4: LOCAL GIT WORKFLOW

Clone, Edit, Commit & Push Workflow

Cloning remote repo locally, making code updates, staging, committing, and pushing back to GitHub.

Terminal Execution Command Walkthrough

# 1. Clone remote repository to local computer

$ git clone https://github.com/jajaalbaladejo27-sys/Intro-to-GitHub.git

# 2. Change directory into cloned folder

$ cd Intro-to-GitHub

# 3. Create or modify files, then stage changes

$ git add .

# 4. Commit changes with a descriptive snapshot message

$ git commit -m "Update local files and add index.html"

# 5. Push committed snapshot back to GitHub

$ git push origin main
